# Masham Chaudhry Personal Portfolio

This project is a personal portfolio website created for ISDS 3100: Information Systems Foundations at Louisiana State University.

## Website Structure

- index.html — Main portfolio page with About, Skills, Experience, and Contact sections
- resume.html — Resume page
- project.html — Project and case study page
- styles.css — Shared styling for all pages

## Tools Used

- Google Antigravity IDE
- HTML
- CSS
- Git
- GitHub
- GitHub Pages

## Reflection

One thing I learned from directing the AI coding agent was that more specific instructions produced more controlled and useful results. When I gave broad prompts, the agent sometimes changed more parts of the website than I intended. I learned to specify which file should be changed, what should remain unchanged, and what result I expected. I also learned that I still needed to inspect and test the agent's output instead of assuming the first result was correct.
